# WP-007 visual assets and treatment

No new logo, manufacturer logo, product photograph or AI image is created.
The UI uses the existing project dark/slate/white/yellow direction with subtle
surface gradients and fine accent rules. These CSS decorations are not logos.

The functional icons are unmodified Lucide SVG files, downloaded from the
official lucide-icons/lucide repository at the exact revision recorded in
assets/lucide/provenance.json. Per-file source URLs and SHA256 hashes are listed.
assets/lucide/LICENSE preserves the complete upstream licence including the
Feather MIT notice where applicable. Official licence: https://lucide.dev/license

These symbols indicate functions and destinations. Rocket is not the Star Citizen
logo; Video is not the OBS logo; Messages is not the Discord logo; CPU is a generic
system icon. Names remain text. No official endorsement is implied.
SVG files are original and unmodified. CSS displays their strokes in white and
at reduced opacity. The licence and provenance files must accompany redistribution
and any future native widget packaging that includes these assets.

No external runtime requests: assets are served from local relative paths.
No font files, Canva templates, Adobe stock or user-account media are imported.
The approved project logo board and product-image composites are not repurposed
as a control icon; they remain untouched.

This is a visual proposal for the approved navigation structure. Browser tests
are required again; physical readability and low-light acceptance remain pending
for a later native candidate. The accepted v0.2.0 widget remains unchanged.
