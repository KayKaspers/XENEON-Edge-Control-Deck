# Brand Guide — XENEON Edge Control Deck

- **Work Package:** XEE-WP-002A
- **Status:** Human-Maintainer approved visual baseline
- **Design authority:** project-local consumer identity under CDS target-state assumptions

## Identity principles

### Technical

Precise, structured and engineered rather than decorative.

### Functional

Visual hierarchy serves interaction, status and readability.

### Premium

Quiet confidence, disciplined spacing and limited accent use.

### Community-friendly

Clear, reusable and suitable for an open public repository.

## Palette

| Token | Value | Intended use |
|---|---|---|
| XENEON Dark | `#0B0B0B` | Primary dark background |
| Surface | `#1A1A1A` | Secondary surfaces |
| Slate | `#2A2F36` | Dividers, secondary framing and muted surfaces |
| White | `#FFFFFF` | Primary text and high-contrast content |
| Accent Yellow | `#FFD600` | Focus, selected accents and identity emphasis |

### Colour rules

- Accent Yellow is restrained, not a full-surface default.
- Colour must not be the sole carrier of semantic state.
- Status semantics remain governed by the XENEON Product Profile and CDS consumer contract.
- Avoid rainbow/RGB-gaming treatment as the project identity.

## Typography

### Display / branding

**Exo 2**

Use for:

- project title;
- large display headings;
- brand-oriented graphics.

### UI / documentation

**Inter**

Use for:

- body text;
- technical labels;
- UI examples;
- supporting documentation.

Repository Markdown does not require local font files and must remain readable with platform defaults.

## Logo / mark

The approved identity uses an independent geometric **X / edge** motif.

Rules:

- keep the mark visually independent from CORSAIR;
- do not incorporate the CORSAIR sail logo;
- do not stretch or distort the mark;
- avoid unnecessary glow, bevel and RGB effects;
- monochrome or Accent Yellow/White treatment is preferred on dark backgrounds;
- preserve sufficient clear space.

## Product imagery

For official project branding:

- prefer real XENEON Edge imagery;
- do not use AI-generated substitute hardware as if it were the XENEON Edge;
- if suitable real imagery cannot be used, omit the device image;
- do not publish the original product-image source separately unless its provenance and reuse rights are appropriate for a public repository.

The approved banner composition uses the Human-Maintainer-provided XENEON Edge source image as the device reference.

## Banner

README banner target:

- `1600 × 400`
- dark technical layout;
- project identity on the left;
- real XENEON Edge imagery where permitted;
- no false vendor affiliation.

## Social preview

GitHub social preview source:

- `1280 × 640`
- derived from the approved banner language;
- retains project title and recognisable product identity.

## Do

- use strong contrast;
- use modular layouts;
- use clear hierarchy;
- keep spacing deliberate;
- keep imagery authentic;
- make project independence clear.

## Do not

- use the CORSAIR logo as the project mark;
- recreate the XENEON Edge with generative AI for official branding;
- use rainbow RGB styling as the identity baseline;
- imply formal CDS conformance;
- imply official CORSAIR affiliation;
- overload layouts with decorative gaming motifs.

## Change control

Material changes to:

- primary palette;
- logo/mark geometry;
- typography direction;
- banner identity;
- official imagery policy

require a new governed design decision rather than silent replacement.
