# Branding — XENEON Edge Control Deck

This directory contains the project-local identity baseline approved during XEE-WP-002A.

## Purpose

The branding provides a consistent public identity for:

- GitHub README presentation;
- GitHub social preview;
- project documentation;
- future screenshots and diagrams;
- project-local UI demonstrations.

It does not define or replace the Core Design System.

## Identity

The project identity is:

- technical;
- functional;
- premium;
- community-friendly;
- dark and high-contrast;
- restrained rather than RGB-heavy.

The project identity must not imply that it is an official CORSAIR product, CORSAIR software, or CORSAIR-maintained repository.
